# 戦国妖異譚 Ver.0.1

スマートフォン縦画面の戦国×妖怪セミオートバトルPWA。
織田信長・真田幸村・上杉謙信の通常攻撃は自動。気力100%で各武将の奥義札をタップ。敵は天狗。HP・ダメージ・勝敗・再戦・一時停止を実装。

## 起動

`python3 -m http.server 8080` をこのディレクトリで実行。

## GitHub Pages

新規公開リポジトリ `sengoku-yokai` に本ディレクトリをアップロードし、Settings → Pages → Deploy from a branch → main / root を選択。

## 素材

以前の背景・武将・天狗の設定画を再利用。キャラは設定画の待機ポーズをCSSで切り出して表示。原画像は変更していない。Ver.0.1では紙背景が残るためmultiply合成を使用。今後、透過スプライト化で改善可能。

タイトルは仮称。編成・ガチャ・セーブは今回の実装対象外。画面を離れている間は戦闘を進めない。
