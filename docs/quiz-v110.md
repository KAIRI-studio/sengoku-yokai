# 社会クイズの出典と編集方針（Ver.1.1.0）

全48問を文部科学省『小学校学習指導要領（平成29年告示）解説 社会編』の該当ページに対応させて再作成した。対象学年は同書の学年区分への対応であり、学習済み時期を保証するものではない。

- 発行：文部科学省、平成29年7月。公式サイトに掲載されたPDFを2026年10月16日に取得・確認。
- 掲載ページ：https://www.mext.go.jp/a_menu/shotou/new-cs/1387014.htm
- 使用PDF：https://www.mext.go.jp/content/20230308-mxt_kyoiku02-100002607_003.pdf
- ページ表記：本文のノンブルとPDFビューアー上のページ番号を併記。本文ページ + 4 = PDFページ。
- すべてゲーム向けの独自三択問題。文科省作成・認定問題、公式テストの転載とは表示しない。
- 原文の問題を複製せず、参照箇所の知識を短い問い・選択肢・説明に編集した。選択肢はゲーム用に作成。
- 知識確認に絞った問題集で、資料の読み取り・記述・地域調査を含む社会科全体を網羅しない。
- 国立教育政策研究所『令和4年度 小学校学習指導要領実施状況調査 教科等別分析と改善点（社会）』も調査形式の参考として確認。https://www.nier.go.jp/kaihatsu/shido_r04/pdf/4_2_r4bunseki_shakai.pdf 。この公開調査の問題そのものをゲームに収録したものではない。

## ゲーム内の表示

コース選択に「出題について・参考資料」を追加。各解説には学年・単元と「出典を見る」を設置。出典画面で資料名・章・本文ページ・PDFページを表示し、公式PDFの該当ページと文科省掲載ページにリンクする。外部リンクは別タブで開き、元のクイズの進行は保持する。

## 保存の互換性

出題内容の変更で既存の回答順と問題の意味が食い違わないよう、新しい問題IDを採用。Ver.1.0.9の途中ラウンドのみ終了扱いとし、すでに受け取ったこばん、実際の所有キャラ、編成、クリア記録は保持する。Ver.1.1.0内の途中再開・正解20こばん・二重加算防止は維持する。
